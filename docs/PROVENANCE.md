# Provenance, AI assistance, and asset use

## AI assistance

Development used OpenAI ChatGPT/Codex for substantial coding assistance, iteration, debugging, asset-conversion and inspection scripts, tests, and technical writing. The November 2026 GitHub preparation also used Codex to select files, organize this repository, adapt local paths, write these guides, and run checks.

The human project owner supplied direction, feature requests, feedback, local game installations, and source media. The available files do not provide reliable line-by-line authorship or a complete list of models, prompts, and sessions. No claim is made that all code or artwork was written manually, that AI-generated work is error-free, or that the AI's suggested source attributions have been independently verified. The checked-in geometric icon artwork was generated by project Python drawing scripts; this is not evidence of a separately hand-drawn asset pipeline.

## External software and references

The original project records cite:

- [HenryTutorial](https://github.com/ArcPh1r3/HenryTutorial) as RoR2 modding reference material.
- [CriPakTools](https://github.com/esperknight/CriPakTools) as a CPK format reference; `inventory_cpk.py` retains that attribution.
- [Blender-XFBIN-Importer](https://github.com/Al-Hydra/Blender-XFBIN-Importer), recorded release 2.5.2, for model/animation imports. `patch_importer.py` records a local compatibility patch.
- BepInEx, Harmony, MonoMod, R2API, Risk of Options, Unity 2021.3.45f2, Blender, .NET, Python, Pillow, NumPy, imageio-ffmpeg and vgmstream as build/runtime/asset-processing dependencies.

Vendor distributions and their DLLs are not vendored into this repository. Acquire each dependency from its upstream source and follow its own license. Version references in old notes describe the original development environment; no claim is made that those are current recommendations. The exact extent of any code derived from reference projects has not been independently audited.

## What was deliberately left local

Game installations and archives, extracted/converted media, audio and videos, generated Unity prefabs and bundles, release ZIPs, third-party DLLs/tools, Unity caches, build outputs, personal game profiles, device logs, backup snapshots, and raw inspection/decompilation dumps were left outside the public repository. The original workspaces were not deleted or changed.

The migration preserves current authored source and useful authored notes rather than representing every local file as publishable material. Local absolute paths were replaced with repository-relative paths, explicit parameters, or ignored `local-inputs/` placeholders. Historical asset tools still require their specific local inputs, inventories, and dependency setup.
