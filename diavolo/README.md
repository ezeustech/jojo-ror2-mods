# Diavolo / King Crimson

Experimental Risk of Rain 2 survivor featuring an independent Stand combo, time erasure, Epitaph, charged impale, counters, ground smash, and configurable controller moves.

**AI-assisted development:** ChatGPT/Codex contributed substantially to code, tooling, tests, and documentation. Complete local builds use Eyes of Heaven / All-Star Battle R assets and supplied media. This source repository omits those assets and recordings. Read the [full disclosure](../docs/PROVENANCE.md).

The current assembly version is **2.6.0**. Retained package notes describe **2.5.6** and older milestones. This is an in-progress source snapshot, not a tested release announcement.
